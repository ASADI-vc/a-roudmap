# src-octoverse2025
- **Title:** Octoverse: A new developer joins GitHub every second as AI leads TypeScript to #1 (Octoverse 2025 annual report)
- **Author / Organization:** GitHub (GitHub Staff; GitHub / Microsoft subsidiary)
- **Canonical URL:** https://github.blog/news-insights/octoverse/octoverse-a-new-developer-joins-github-every-second-as-ai-leads-typescript-to-1/ (the URL https://github.blog/news-insights/octoverse/octoverse-2025/ returns 404; report located via the Octoverse index)
- **Publication / update date:** October 28, 2025 (updated February 28, 2026)
- **Access date:** 2026-11-14
- **Source type:** labor/developer-population statistics from a platform telemetry + employer-vendor report (vendor platform data)
- **Research questions addressed:** RQ6 (developer supply/growth, where demand-side activity is happening) and RQ4/RQ7 context (AI tool adoption as measured by platform activity, agent usage)
- **Original summary (own words):** GitHub's annual Octoverse reports record global developer growth — 180 million-plus developers, with 36 million joining in one year — driven heavily by India and other emerging markets, with generative AI now standard in development. Platform telemetry shows TypeScript overtaking Python and JavaScript as the most used language in August 2025, massive growth in AI-related repositories, and agent tools entering the mainstream. GitHub itself flags these as observational correlations, not causal claims.
- **Relevant findings:**
  - **Total developers:** "more than 180 million developers now work and build on GitHub"; "More than 36 million developers joined GitHub in a single year (23% YoY)" — i.e., "over 36 million in the past year," "more than one new developer on average joined GitHub" every second. (Global, year ending 2025.)
  - **Language milestone (exact wording):** "for the first time, TypeScript overtook both Python and JavaScript in August 2025 to become the most used language on GitHub... This marks the most significant language shift in more than a decade." Note: the task's expected "Python overtaking JavaScript" claim was not found in the fetched annual report; it says TypeScript is #1 and "Python remains dominant for AI and data science workloads, while the JavaScript/TypeScript ecosystem still accounts for more overall activity than Python alone." (An earlier 2025 mid-year Octoverse post reportedly named Python #1, but its URL is now 404; not verified.)
  - **AI-related repo growth:** "More than 1.1 million public repositories now use an LLM SDK with 693,867 of these projects created in just the past 12 months alone (+178% YoY, Aug '25 vs. Aug '24). Developers also merged a record 518.7M pull requests (+29% YoY)."
  - **New-dev AI adoption:** "80% of new developers on GitHub use Copilot in their first week" / "nearly 80% of new developers on GitHub use GitHub Copilot within their first week."
  - **Geographic growth (Global South):** India "added more than 5.2 million developers in 2025... a little over 14% of GitHub's total +36 million new developers" — largest source of new developers; APAC +13M net new devs, Europe +6.3M, Africa & the Middle East +3.4M (Nigeria, Turkey, Egypt standouts), LATAM +3.2M (Brazil, Mexico, Colombia). "Over the past five years (from 2020 to 2025), India, Brazil, and Indonesia have more than quadrupled the number of developers on the platform; Japan and Germany have more than tripled...; the USA, UK, and Canada have more than doubled."
  - **2030 projections:** India 57.5M developers, US 40M+, Brazil 19.6M, Japan 11.7M, UK 11M; India "on track to account for one in every three new developers on GitHub by 2030"; Egypt, Nigeria, Kenya, Morocco projected to add millions.
  - **Platform activity:** 1.12B contributions to public/open source projects in 2025; 986M commits pushed (+25% YoY, nearly 1B); monthly avg 43.2M PRs merged (+23% YoY); issues closed 4.25M/mo vs 3.4M in 2024; 630M total repositories, +121M new in 2025; 81.5% of contributions in private repos (public repos 63% of all repos, growing +19% vs private +33%).
  - **Agents/AI tooling:** 2.42M repos with Jupyter Notebooks (+75% YoY), 1.9M with Dockerfiles (+120% YoY, "likely fueled by the need to sandbox agents and LLMs"); "72.6% of developers who use Copilot code review said it improved their effectiveness" (in-depth interviews).
  - **Explicit causal caveat:** "These are observational signals rather than causal claims and more work is needed to understand the full impact AI is having in software development."
  - **Iran note:** No mention of Iran found in the fetched report text (no sanctions/exclusion note visible).
- **Population / methodology / tools:** GitHub platform telemetry (developer accounts, repos, pushes, PRs, LLM SDK usage) for the 12 months ending 2025; growth projections via "regression analysis" modeling by GitHub's data team; 72.6% effectiveness figure from in-depth interviews with Copilot code review users. Not a random sample of developers — it measures activity on GitHub only; private-repo activity (81.5% of contributions) is invisible to outside verification.
- **Limitations / conflicts of interest / applicability:** Vendor (Microsoft/GitHub) sells Copilot and benefits directly from an AI-boom narrative; GitHub population ≠ global developer population (developers on other platforms, GitLab, Bitbucket, or offline/enterprise VCS are excluded); "most used language" is GitHub-specific (pushes/bytes methodology); projections (2030) are modeled forecasts; Copilot-usage-in-first-week measures account creation, not employment or output quality. Report itself concedes correlation ≠ causation.
- **Candidate claims supported:**
  - observed: 180M+ developers on GitHub; +36M new accounts in one year (23% YoY) (Oct 2025 report).
  - observed: TypeScript overtook Python and JavaScript in August 2025 as most used language on GitHub.
  - observed: 1.1M+ public repos use LLM SDKs; +178% YoY growth in new such projects (Aug '25 vs Aug '24).
  - forecast: India to reach 57.5M developers by 2030; 1-in-3 new developers from India (model-based projection).
- **Implications for learners:** The global developer supply is exploding fastest outside the US (India, Brazil, Indonesia, Africa/MENA) — competition for entry-level roles is globalizing, while AI-native workflows (Copilot in first week for 80% of new joiners; typed languages like TypeScript) are becoming the default. Differentiation now comes from portfolio evidence on public GitHub and skills AI cannot yet replace.
- **Confidence:** high for quoted figures (fetched verbatim from official GitHub blog report); medium on the Python-vs-JavaScript question, since a mid-year 2025 Octoverse iteration (possibly naming Python #1) is no longer retrievable at its URL.
- **Access status:** full (annual report page; methodology appendix and underlying datasets not separately downloaded)
