## Method notes
- 39 notes for ~38 underlying sources; Ziegler et al. and Peng et al. describe overlapping GitHub experiments and are kept as separate notes (different documents, different figures).
- Articles that merely repeated the same study were collapsed into the underlying source's note (e.g., GitClear coverage).
- Corrections made during research: DORA 2024 n≈3,000 (39,000 = decade-cumulative); Barke arXiv ID is 2206.15000; OWASP Top 10 2025 edition supersedes 2021; Octoverse 2025: TypeScript (not Python) became the most-used GitHub language in Aug 2025; WCAG 2.2 is a W3C Recommendation dated 12 December 2024.
- Inaccessible after retries: BLS OOH page (403; O*NET supplement used), McKinsey report body (bot-blocked; publisher-indexed text + publisher announcement used), GitClear canonical page (Cloudflare 403; secondary coverage used), sagepub full text for Adesope (Cloudflare; ERIC abstract + Wing Institute summary used).
